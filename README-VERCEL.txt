ASHFORD COMMUNITY ENERGY - VERCEL TRANSFER PACKAGE

This ZIP contains the current ACE website source.

Suggested route:
1. Unzip this folder on your Mac.
2. Create a GitHub repository named ace-website.
3. Upload this folder to that repository.
4. In Vercel choose Add New > Project and import ace-website.
5. Set Root Directory to: app

CONTACT FORM
The current live ACE contact form uses Cloudflare D1. The website design, pages and animation are included here, but the contact form backend will need adapting before live public use on Vercel.
